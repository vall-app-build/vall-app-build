🐙 BUKA GITHUB 🚀 BUKA RAILWAY
1. Buat akun GitHub.
2. Upload source code backend Putra APK Builder.
3. Hubungkan repository GitHub ke Railway.
4. Deploy backend dengan Java, Android SDK, Gradle, Node.js, dan Python.
5. Masukkan URL deployment ke kolom backend.

📖 Panduan Penggunaan

1. Siapkan file HTML atau ZIP.

2. Siapkan URL backend cloud.

3. Isi nama aplikasi dan package name.

4. Upload file HTML.

5. Tekan BUILD APK + MEDIAFIRE.

6. Tunggu proses build dan upload selesai.
